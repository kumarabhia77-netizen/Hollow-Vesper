# Hollow Vesper
An original 2D dark-fantasy action game. Open index.html (or your GitHub Pages link) to play.

Keyboard: A/D or arrows move, Space jump, J Gilded Thorn whip (3-hit combo; Resonance builds as you hit, and at 60 the third lash is the Rupture Lash), Shift dash, K and I cast your two equipped spells, B Bell Resonance, M world map, Tab magic menu, P or Esc pause.
Phone: on-screen gamepad (customise it in Pause > Controls). A game controller also works.
Add ?debug to the address to see hitboxes.
If a red message says "Please upload the newest: js/..." then that file is old or missing in your repo.

See docs/WHIP_AND_BELL_RINGER_NOTES.md for the Gilded Thorn whip, Bell-Ringer resonance and timing numbers.
